红果短剧 OpenWrt 插件 0.1.0-r1（测试版）
====================================

适用：OpenWrt 25.12.x，x86/64（APK 架构 x86_64），现代 LuCI。
已按你提供的 J1900 / 1GB 内存配置设置保守默认值。
这是非官方移植版本；尚未在你的虚拟机上完成真实播放验收。
这里的 .apk 是 OpenWrt 软件包，不是 Android 安装包。

一、安装

1. 解压 ZIP，把 luci-app-hongguo-0.1.0-r1_x86_64.apk 上传到 OpenWrt 的 /tmp/。
   可用 WinSCP、SFTP，或在支持本地包上传的“系统 → 软件包”页面上传。
2. 最可靠的安装方式是 SSH 登录 OpenWrt 后执行：

   apk add --allow-untrusted /tmp/luci-app-hongguo-0.1.0-r1_x86_64.apk

   这是本地未签名包，所以需要 --allow-untrusted。不要改用 opkg，也不要使用
   --force-broken-world。若提示缺少依赖，先执行 apk update，再重试上面的命令。
   如果固件的软件源已失效，请先修复该固件的软件源，不要随意混用其他版本。
3. 刷新 LuCI（必要时 Ctrl+F5，或退出账号后重新登录）。
   打开“服务 → 红果短剧”。安装后服务默认关闭，不需要重启路由器。

二、首次启用

1. 设置“观看密码”：12～128 位可见 ASCII 字符，不含空格。
2. 保持监听地址 0.0.0.0，观看端口 8797（或选择未占用端口）。
3. 勾选“启用服务”，点击“保存并应用”。
4. 状态变为“运行中”后，点击“打开观看页面”；也可手动访问：

   http://OpenWrt的LAN_IP:8797/

5. 浏览器首次弹出认证框：用户名 hongguo，密码填写刚才设置的观看密码。
   这组凭据不是 OpenWrt root 密码，也不是红果账号密码。
6. 网页进入后，可使用原项目的浏览、搜索、选集和播放功能。
   红果账号登录另在观看网页中完成，多个设备共用同一套账号/历史/收藏。

访问地址必须使用私网 IPv4 地址，不支持主机名和 IPv6。
观看页面默认启用适合鼠标和键盘的桌面交互。
想保留原 TV 页面交互，可访问 http://OpenWrt的LAN_IP:8797/?platform=tv 。

三、你的 1GB 内存 / 1GB 硬盘应如何配置

默认：
- 缓存目录 /tmp/hongguo-media：使用 RAM，重启清空。
- 缓存清理阈值 64 MiB：清理已完成的旧媒体缓存，不是总 RAM 硬上限。
- 完整视频单文件上限 32 MiB：超过上限的完整下载会失败。
- 视频准备并发 1：限制同时解析/准备的视频任务。
- Go 内存回收目标 192 MiB：软目标，不是进程硬内存限制。
- 观看历史及红果账号数据 /etc/hongguo：持久保存。

按需 Range 播放不要求将整个视频下载到路由器，因此视频总长度可超过单文件上限。
完整文件回退路径超过 32 MiB 时会失败；先查日志，再根据余量调整设置。
缓存大小之外，还需要为处理中视频、媒体索引和程序本身保留内存。

建议新增一块 4～8GB 虚拟数据盘，挂载后把缓存目录改为：
/mnt/你的挂载点/hongguo-cache

必须使用 hongguo-* 专用目录。服务会拒绝未挂载的 /mnt 路径，避免把缓存写入
系统盘。不会自动分区、格式化、挂载或清空你的数据盘。

四、管理和排查

- 配置入口：服务 → 红果短剧。
- “重启服务”使用已经保存的配置；编辑后请先保存并应用。
- “临时停止”只停止当前运行；取消启用并保存应用可禁止下次启动服务。
- 日志：状态 → 系统日志，查找 hongguo；SSH 可执行 logread -e hongguo。
- 命令行重启：/etc/init.d/hongguo restart
- 命令行停止：/etc/init.d/hongguo stop
- 查询启用状态：uci get hongguo.main.enabled
- 卸载：apk del luci-app-hongguo
  卸载前如需保留账号和进度，请备份 /etc/hongguo 和 /etc/config/hongguo。

页面打不开：核对 OpenWrt IP、端口、服务状态和现有防火墙规则。
爱快虚拟机环境中，如果访问入口被 OpenWrt 划为 WAN，现有规则可能阻止访问。
本包不修改网络、DHCP、DNS、防火墙或爱快配置，请优先从 OpenWrt LAN 侧访问。
仅在可信局域网使用 HTTP，不要给观看端口添加公网映射。

页面能打开但视频不能播：查看日志；首先核对观看设备浏览器的视频编码支持。
网页版使用浏览器解码，没有 Android Media3/MPV 兜底，也不在路由器实时转码。
上游接口变化、网络条件、账号状态和 HEVC 解码支持都可能影响真实播放。
